{% comment %} Shared drag-and-drop wiring for the page content editor. Two kinds of list are draggable, and both work the same way: drag a row by its handle, the new order is POSTed as JSON, and a status line reports the result. [data-sortable="sections"] the page's sections -> page_sections_reorder [data-sortable="source"] the items inside a source -> content_source_reorder A third interaction drops a *new* block: dragging a palette tile into the section list posts the source key and the position it landed at. Everything degrades safely. If Sortable fails to load, the palette tiles are still buttons that append a block, and each section keeps its ↑/↓ controls. {% endcomment %}
