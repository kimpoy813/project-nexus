Repeatable group

Print these fields once per row so the proponent can enter several of the same thing - several proponents, several beneficiaries, several partners. Each row is saved separately.

Used on the "Add …" button.

Rows required before the step is complete.

0 = no limit.

Choosing Proponents of the proposal makes each row a real proponent record, so the generated documents, the review screens, and the dashboards keep working. Map fields onto Name, Position / Designation, Specialization, Role, CP Number and Email so they fill those columns; unmapped fields are kept as extra details of that proponent. File upload fields are not available inside repeatable groups - add those as normal fields on the step.
