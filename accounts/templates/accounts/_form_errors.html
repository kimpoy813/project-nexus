{% comment %} A summary of everything that went wrong, placed at the top of the form. Why a summary and not only the per-field messages: after a rejected submit the browser keeps the user at the bottom of the page, next to the button they just pressed. The summary is focusable and `js/nexus-forms.js` moves focus to it on load, so a keyboard or screen-reader user hears the problem immediately. Every line is a link to the field it belongs to, so the fix is one keystroke away. Usage: {% include "accounts/_form_errors.html" with form=form %} {% endcomment %} {% if form.errors %}

Please correct the following before continuing:

    {% for field in form %} {% for error in field.errors %}
  • {{ field.label }}: {{ error }}
    • {% endfor %} {% endfor %} {% for error in form.non_field_errors %}
  • {{ error }}
    • {% endfor %}
{% endif %}
