{% comment %} The single mount point for every piece of feedback NExUS gives. Django's messages, the dashboards' AJAX handlers, the wizard's in-page swaps and the Django admin all end up in one function: window.nexusToast(message, type) // type: success | error | warning | info It uses the Gooey toaster when it has loaded and falls back to the plain toast below when it has not, so feedback never depends on the 386 KB module arriving. Include this as the last thing a full page renders (templates/base.html, maintenance, debug-login, the Django admin) and link static/goey/toaster.css from the head. Why messages are queued: toaster.js is a module, so it runs *after* the whole document is parsed, while an inline script — or the admin's own message list — may raise a toast while the page is still parsing.
